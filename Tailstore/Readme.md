TailStore -- Fashion E-Commerce Website

A modern, responsive fashion e-commerce website built using HTML, CSS,
and Bootstrap 5.

The project recreates a TailStore-style fashion storefront with a
responsive navigation bar, hero slider, product sections, brand section,
shop banner, blog cards, newsletter area, and footer.

The main theme color is controlled by the CSS variable:

}

Change this value to change the primary color throughout the website.
